# HEART RELAY デモ動画 台本 v2（2026-11-08）

Deuce-M レビュー（2026-11-08）を反映。v1 の実画面素材を再利用し、**再収録なし**。実測 **2 分 55 秒**（175.3 秒）。
全カット本番 Claude（claude-sonnet-5-5）の実出力。登場する利用者・職員・事業所はすべて架空。

## v1 からの主な変更
1. 冒頭に **課題提示スライド**（架空の送迎トラブル）を追加。核心は「情報は届いていた。必要な人に、伝わらなかった。」
2. ナレーションを UI 実況から **「AI が整理・提案し、人が確認・決定する」** 構造へ全面書き直し。
3. 宛先の選定理由・除外理由、Android 確認 → PC 反映を重点化（カット 5・8 を延長、カット 5 は「宛先の増減は人が決める」を明言）。
4. 法人内連絡で「Claude は件名・本文の**案**まで。送信は人の操作だけ。AI が送ることはない」を明言。
5. ナレーションは Open JTalk を維持し、速度 1.15→1.05、文間に 0.45 秒の無音、**字幕を文単位でナレーションに同期**。
6. 音声入力は「実装済みだが、この動画では実演していない」と明示（カット 2）。
7. 不正確な表現の除去: 「200 名から AI が特定」→「本文を**台帳と照合**し、利用者を特定」（照合は ID・氏名・カナの決定的一致、曖昧なら職員が選ぶ、と注記）。「AI が自動送信」に読める表現なし。
8. 締めを「情報を集め、AI が整理し、人が判断し、確認までつなぐ」に統一（タイトル・まとめスライドも同文）。
