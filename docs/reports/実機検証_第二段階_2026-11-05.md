## 発見した不具合と対応
| 事象 | 原因 | 対応 |
|---|---|---|
| 「両方」に切り替えると掲示本文の初期値に健康情報（発熱等）が入る | `web/app.js` が `summary`/`board_summary` を初期値に流用、プロンプトも board_summary に健康情報を書いていた | プロンプト方針追記＋初期値を空に（`b94780c`）。実機で誤って掲示された 2 件は archive 済み |
| 「担当看護師」など台帳に無い区分を本文に書く | プロンプトの指示不足 | 方針追記（`b94780c`） |
| 配信後も連絡内容欄・添付が残り、次の文書が追記されて複数人の文書になる | `sendMessage` 成功時に入力をクリアしていない | 配信成功時にクリア（本記録後のコミット参照） |
| `.cmd` が黒画面一瞬で終了 | `( )` ブロック内の echo に括弧 → cmd 構文エラー | 括弧除去。selftest で再発防止 |
| Wi-Fi 直結で Pixel から到達不可 | 未特定（PC 側は待受・FW 許可済み） | adb reverse 経路で代替。デモは同経路で可 |
