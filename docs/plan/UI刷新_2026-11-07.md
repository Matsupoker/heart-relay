# UI 刷新 設計記録（2026-11-07）

[オーナー決定] Google Drive の承認済みモック `HEART_RELAY_UI_01_home.png` / `HEART_RELAY_UI_02_delivery_management_selected.png` に沿って、現行 3 カラム UI をホーム／配信管理／新規連絡の画面構成に刷新する。既存機能（Claude 解析・ファイル入力・配信・Android 確認・共有ボード）と API/DB は変えない。Issue #2（法人内複数事業所）は今回実装しない。

## 画面構成（[Fable 提案]、モックに準拠）
単一ページ `web/index.html` のまま、ハッシュルーティングでビューを切り替える（ビルド不要・既存 API のみ）。

| ルート | 画面 | 内容 |
|---|---|---|
| `#/home`（既定） | ホーム | ヒーロー「連絡事項を送信する」＋主ボタン「新しい連絡を作成 →」（→ `#/new`）、副導線「文章を入力」（→ `#/new`、本文欄にフォーカス）「ファイル・写真を取り込む」（→ `#/new` でファイル選択を開く）、3 ステップ表示、「今日の連絡」（本日 JST に配信した連絡の **配信件数・未確認件数・確認完了件数** と、連絡ごとの行: 利用者名｜分類・要約｜確認状況｜配信状況を見る → `#/deliveries/<id>`）。「配信状況を見る ›」見出しリンク → `#/deliveries` |
| `#/new` | 新規連絡 | 現行の「入力」「提案（候補選択・利用者変更・届け方・掲示編集・除外一覧・承認）」を 2 カラム（PC）／縦積み（スマホ）で表示。配信成功後は `#/deliveries/<id>` へ遷移 |
| `#/deliveries` | 配信管理 | 左: 連絡一覧（既定は本日、「すべて」切替で過去分も。利用者名／分類（categories[0] か summary 先頭）／確認 a/b／緊急度の色帯）。右: 選択した連絡の詳細（PC は 2 ペイン、スマホは一覧→詳細の 2 画面） |
| `#/deliveries/<id>` | 配信詳細 | 見出し「<利用者名>様｜<要約短>」（利用者なしは要約のみ）、AI 要約（summary）＋情報の出所（source）、進捗ステップ（情報を受信 → AI が通知先を提案 → 職員が承認 → **確認完了**）、表「通知先（役割）｜担当者｜AI による通知理由｜確認状況（確認済 hh:mm／未確認）」、「AI による選定理由」（excluded_note＋除外職員と理由を折りたたみ）、共有ボード掲示の有無（掲示中／掲示終了） |
| 共有ボード | 既存 `board.html` | ナビから新しいタブで開く（変更なし） |

### ナビゲーション
- PC: 左サイドナビ（ホーム／新規連絡／配信管理／共有ボード）。ヘッダ: ロゴ、事業所名（固定文字列「デイサービス（架空）」、ドロップダウンは置かない＝Issue #2 まで）、本日の日付（実日付）、操作者（職員 select。既存 `created-by`）、「＋新規連絡」。
- スマホ（≤900px）: 上部にロゴ＋「＋新規連絡」、下部に固定タブ（ホーム／新規／配信／ボード）。

### モックとの意図的な差異（[Fable 提案]、オーナー指示「架空数値・未実装操作を使わない」に基づく）
- 「法人内連絡（準備中）」はナビに置かない（Issue #2 で追加）。
- 「未確認者に再通知」リンクは置かない（P2 未実装）。
- ベルアイコン（通知）は置かない（未実装）。
- 進捗ステップの最終項目はモックの「個別に配信」ではなく「確認完了」（全員確認で達成）とし、配信済みで未確認が残る状態を正しく表す。
- 件数・日時・確認状況は `/api/messages` の実データから算出。「今日」は JST の日付。

## 維持するもの
- `data-testid` は全て維持（E2E・実機手順が依存）。新規: `nav-home`, `nav-new`, `nav-deliveries`, `nav-board`, `home-stat-sent`, `home-stat-unacked`, `home-stat-acked`, `home-row`, `dl-list-item`, `dl-detail`, `dl-step`, `dl-recipient-row`, `dl-reason`。
- `web/app.js` の API 呼び出し・状態遷移（submit → needs_resident → resident → proposed → send）はそのまま。
- `web/dev/mock-server.mjs` は変更不要（契約同じ）。`web/dev/e2e.cjs` / `e2e-real.cjs` は画面遷移に合わせて更新。
