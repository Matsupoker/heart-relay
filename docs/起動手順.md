# 起動手順（第一段階デモ環境）

PC 1台（Windows）＋ Android 実機 1台で、「入力 → AI解析 → 個別配信 → 確認しました → PC反映」を動かす手順です。
**扱うデータはすべて架空です。**

## 0. 必要なもの
- Windows PC: Node.js 22 以上（`node -v` で確認）
- Android スマートフォン（Android 8.0 / API 26 以上）
- PC とスマホが同じ Wi-Fi に接続されていること
- Claude API キー（無い場合はモック解析で動きます）

## 1. バックエンド＋PC画面を起動（Windows PC）
```
git clone https://github.com/Matsupoker/heart-relay.git
cd heart-relay\backend
npm install
copy .env.example .env
notepad .env        ← ANTHROPIC_API_KEY=sk-ant-... を記入して保存（モックで試すなら空のまま）
npm run seed
npm start
```
ブラウザで http://localhost:8787 を開くと PC 画面が出ます。右上のバッジが「Claude API（モデル名）」なら本番解析、「モック解析」ならキー未設定です。

初回起動時に Windows のファイアウォール確認が出たら「プライベートネットワーク」を許可してください。出なかった場合は管理者 PowerShell で:
```
New-NetFirewallRule -DisplayName "HEART RELAY 8787" -Direction Inbound -Protocol TCP -LocalPort 8787 -Action Allow -Profile Private
```

## 2. PC の IP アドレスを調べる
コマンドプロンプトで `ipconfig` → Wi-Fi アダプターの「IPv4 アドレス」（例 `192.168.1.23`）。
スマホのブラウザで `http://192.168.1.23:8787/api/health` を開き、JSON が表示されれば LAN 疎通 OK。

## 3. Android アプリをインストール
- 配布された `heart-relay-debug.apk` をスマホにコピーして開く（「提供元不明のアプリ」の許可が必要）、または USB デバッグで `adb install -r heart-relay-debug.apk`
- 自分でビルドする場合は `android/README.md` を参照

## 4. アプリの初期設定
1. 起動 → サーバー URL に `http://192.168.1.23:8787`（手順2のIP）を入力 → 「接続確認」
2. 職員一覧から 1 名を選ぶ（例: 運転手「竹内 康介」）
3. Android 13 以降は通知の許可ダイアログで「許可」

## 5. デモの流れ
1. PC 画面左のサンプルボタン「青木様（r01）は本…」→「AIで解析する」
2. 中央に AI 提案（分類・緊急度・宛先候補と職種別の本文）が出る。内容を確認・修正して「承認して配信」
3. スマホに通知が届く → 開いて「確認しました」
4. PC 画面右の確認状況が数秒以内に「✅ 確認済み」に変わる

## トラブルシューティング
| 症状 | 確認すること |
|---|---|
| スマホから接続できない | 同じ Wi-Fi か／PC のファイアウォール／IP の打ち間違い／ルーターの「AP アイソレーション（プライバシーセパレーター）」が有効だと端末間通信が遮断されます |
| 解析が `failed` になる | バックエンドのコンソールのエラー文（API キー・モデル名・残高）。「再解析」で再試行 |
| 通知が来ない | アプリを前面に出したままにする（第一段階は前面時のみポーリング）。通知許可を確認 |
| 429 が出る | 1 分あたりの解析上限（既定 10 回）。少し待つ |
